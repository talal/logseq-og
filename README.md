# Logseq OG Fork

This project is a fork of Logseq OG.

[Logseq OG](https://github.com/logseq/og) refers to v1.0.0 which was the last
version that supported file-based graphs (Markdown). The newer and current
version of [Logseq](https://github.com/logseq/logseq) uses database graphs
(SQLite). See the
[this post](https://logseq.io/page/b2ad9ce1-9cb7-4436-8083-54cb4516d324/df4dc09d-0a12-4c87-904e-22a9bf4c350a)
for more details.

I created this fork because I don't plan to switch to database graphs and will
continue to use file-based graphs. Please read the [disclaimer](#disclaimer).

## Core Principles

Instead of accumulating features and targeting every use-case, this project will
focus and prioritize the following principles:

1. **Stability:** no crashes or data loss
2. **Performance:** minimal latency, no lag or stutter — _Take notes at the
   speed of thought_
3. **Maintainability:** keep codebase as small and minimal as practical

## Disclaimer

I created this fork primarily for my **personal use**. I have made this
repository public for education purposes and in case others might find it
useful. I have no intention of supporting end-users and if you use this fork
then you should **not expect any support** from me.

This means that I will only add or remove features/functionality which make
sense and are beneficial to me.

However, if the app violates any of the [core principles](#core-principles)
listed above then feel free to
[open an issue](https://github.com/talal/logseq-og/issues/new/) and I will fix
it. For example, if the app crashes (Principle #1) or if the app is slow
(Principle #2) then you may open an issue. Please don't open issues where you
ask for feature requests because I'm the one who will have to maintain this fork
and I would like to keep it easy to maintain (Principle #3).
